# فروشگاه سوپر بهزاد — نسخه آغازین Full-stack

## محتویات
- `public/index.html`: فرانت‌اند فعلی فروشگاه (با نوار تشخیص اتصال API)
- `server.js`: بک‌اند Node.js/Express و APIهای کالا، سفارش، مدیریت، کوپن، پک، گردونه و VIP
- `store.db`: دیتابیس SQLite که بار اول اجرا به‌صورت خودکار ساخته می‌شود
- `package.json`: وابستگی‌ها

## اجرا روی رایانه/هاست Node.js
1. Node.js نسخه 20 یا جدیدتر نصب کنید.
2. در پوشه پروژه اجرا کنید: `npm install`
3. متغیرهای محیطی تنظیم شوند:
   - `JWT_SECRET`: یک رشته تصادفی طولانی و محرمانه
   - `ADMIN_PASSWORD`: رمز مدیریت قوی
4. اجرا: `npm start`
5. مرورگر: `http://localhost:3000`

## هشدار مهم
این بسته شامل بک‌اند و دیتابیس اولیه است و بخش‌های مهمی از فرانت‌اند (ورود مدیریت، بارگذاری کالاها، ویرایش کالا، ثبت سفارش سروری، وضعیت سفارش، کوپن، پک، گردونه و VIP) به API وصل شده‌اند. برای شروع، پس از ورود مدیریت دکمه «همگام‌سازی کالاهای اولیه با دیتابیس» را فقط وقتی دیتابیس خالی است اجرا کنید. پرداخت بانکی واقعی هنوز متصل نیست. گردونه و VIP در API نمونه هستند و نیازمند بررسی امنیتی/سیاست حفظ داده پیش از بهره‌برداری عمومی‌اند. برای اینترنت عمومی، HTTPS، پشتیبان‌گیری، مدیریت secrets، اعتبارسنجی بیشتر و تست عملی لازم است.

## اجرای آسان
- ویندوز: روی `start-windows.bat` دوبار کلیک کنید.
- لینوکس/macOS: `./start-linux.sh`
- سپس مرورگر را روی `http://localhost:3000` باز کنید.
- رمز مدیریت نسخه فعلی: `1020`

## نکته پرداخت
ثبت سفارش آنلاین و مدیریت سفارش فعال است، اما پرداخت بانکی واقعی تا زمانی که درگاه بانکی و مشخصات پذیرنده متصل نشود فعال نمی‌شود.

## نسخه نهایی — اصلاحات پایدارسازی
- تنظیمات فروشگاه در SQLite ذخیره می‌شود و با خروج و ورود دوباره برنمی‌گردد.
- تغییر رمز مدیریت در دیتابیس به‌صورت هش‌شده ذخیره می‌شود و بعد از restart سرور باقی می‌ماند.
- رمز اولیه این بسته: `1020` (برای سایت عمومی حتماً پس از ورود آن را به رمز قوی‌تر تغییر دهید).
- سفارش آنلاین، کنترل موجودی، وضعیت سفارش و وضعیت پرداخت در پنل مدیریت قابل پیگیری است.
- پنل مدیریت سفارش‌ها را هر ۳۰ ثانیه برای سفارش‌های جدید تازه می‌کند.
- داشبورد فروش، کالاهای کم‌موجودی و پرفروش‌ها فعال است.
- اسکریپت `backup-db.sh` برای تهیه نسخه پشتیبان از SQLite اضافه شده است.

## نکته مهم انتشار عمومی
پرداخت واقعی زرین‌پال فقط پس از وارد کردن `ZARINPAL_MERCHANT_ID` و `PAYMENT_CALLBACK_URL` روی دامنه HTTPS فعال می‌شود. پیامک واقعی نیز به `SMS_API_KEY` و `SMS_FROM` نیاز دارد.
